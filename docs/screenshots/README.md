## 更新或补充截图

1. 启动服务，在**正常大小的浏览器窗口**里打开 <http://127.0.0.1:5177/>
   （宽 1400–1600 px 效果最好；内置预览面板只有几百像素宽，截出来会变形）
2. 按上表命名保存到本目录，然后在 `README.md` / `README.en.md` 的「截图」一节里引用
3. 保持整页宽度一致，表格里 2 列 / 3 列排布才不会错位

## 脱敏建议

这些截图会公开在仓库里，发布前请确认没有泄露隐私，必要时打码：

- **书名与笔记原文**：最能暴露阅读偏好
- **阅读时长 / 天数 / 排名**：属于个人信息
- **勋章**：活动勋章会带获得日期与排名（如「第 58801 位获得」）
- **私密书籍**：界面会打「私密」标记，一眼可辨
- **浏览器地址栏与书签栏**：容易带出其它账号信息
- 切勿截到弹窗或控制台里 `wrk-` 开头的 API Key

如果只想展示排版而不暴露数据，可以把书名和原文用纯色块盖住，保留图表与布局即可。
